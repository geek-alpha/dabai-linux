扫码图未生成，直接在手机浏览器输入：

1
装根证书（只需一次）

手机必须信任这张自签 CA，浏览器才允许注册离线缓存层。点下面按钮下载。

下载根证书 dabai-ca.crt
iPhone / iPad 安装步骤

下载后打开「设置」→ 顶部会出现「已下载描述文件」→ 安装（要输锁屏密码）→ 再到「设置 → 通用 → 关于本机 → 证书信任设置」，把 Dabai Local CA 的开关打开。

Android 安装步骤

下载后打开「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」，选择刚下载的 dabai-ca.crt。华为/小米等机型入口在「设置 → 安全 → 更多安全设置」里，认准「CA 证书」。

2
回到白头凤，刷新一次

证书生效后地址栏不再报「不安全」，页面会自动把 3D 模型以外的资源缓存到手机本地，第二次打开基本瞬间进入。

打开白头凤
3
加到主屏幕

iPhone：Safari 分享按钮 → 「添加到主屏幕」。
Android Chrome：右上角 ⋮ → 「安装应用」/「添加到主屏幕」。之后从图标进，全屏、无浏览器地址栏。
