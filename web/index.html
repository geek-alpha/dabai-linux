支持 GLB / GLTF / VRM，单文件 ≤ 80MB
留空「供应商」= 跟随当前全局使用的供应商；选好后下方自动加载它的模型列表
模型只从所选供应商加载，不会串用其它提供方的模型
越低越稳定听话，越高越自由放飞（0 ~ 2）；保存后该卡片应用时生效
这张卡绑的模型能不能吃图。选「不支持」只是不再拿它试，读图仍会找其它视觉模型代看。
应用配置都在角色卡片；地址 / 密钥 / 模型 / 音色按本卡片保存并生效

语音转文字专用的 Key，与大语言模型的 Key 相互独立；留空则沿用大语言模型的 Key
开启后，该角色可自主调用下方勾选的能力（换装 / 切场景 / 放音乐 / 查信息 / 玩游戏等）

开启后，该角色只执行下方勾选的动作（待机/情绪/手势等都会从勾选的动作里挑）；关闭或未勾选任何动作 = 执行全部动作
