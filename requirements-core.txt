# 大白跨平台依赖清单（Windows / Linux / macOS 通用）—— 唯一权威
#
# 为什么不用 requirements.txt：那份是早期那台 Windows 机器上的历史清单，混了三类装不上的东西 ——
#   bpy / bmesh / mathutils / addon_utils / rna_prop_ui  Blender 内嵌 Python 才有，PyPI 上没有
#   imp                                                 Python 3.12 起已从标准库移除，安装即失败
#   TodoService / amazing_agent_dingding / dabai_ears /
#   dabai_voice / fuctions_all_you_need_base / google   本机私有包，PyPI 上不存在
# 拿它在新机器上装会成片失败，看着像环境坏了，其实是清单本身不可移植。
# anthropic / python-dotenv 也是从那份抄过来的，全仓代码零引用 —— 已移出清单（见文末可选段）。
#
# 与 tools/check_deps.py 同源：那份是启动前自检的清单，改这里要同步改它
# （本文件的「启动必需 / 能力依赖」两段与 check_deps.py 的 REQUIRED / CAPABILITY 对应）。
#
# 清单完不完整不靠人肉保证 —— tools/deps_audit.py 从 server.py 沿 import 图反推对账：
#   python3 tools/deps_audit.py           # 报告：启动路径依赖 vs 清单，标出漏网/冗余
#   python3 tools/deps_audit.py --gate    # 启动路径有漏网或未装 → 退出 1（可挂 CI）
#   python3 tools/deps_audit.py --export  # 一键导出本机实际依赖（代码 import 反推，带版本）
#   python3 tools/deps_audit.py --freeze  # 一键导出完整环境锁定（pip freeze 全量）
#
# 安装：
#   Linux/macOS  ./dabai.sh --setup      （或 tools/linux_setup.sh --venv）
#   Windows      dabai.bat --setup
#   pip 源慢/超时：python tools/pip_mirror.py -r requirements-core.txt  # 自动探测可用镜像
