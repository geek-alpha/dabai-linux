# 中途问用户（ask）

给模型一个「问完等答案」的真实通道，而不是把问题写进正文、然后结束回合等用户下一句。

## 什么时候用

- **该用**：查不到的偏好与取舍（选哪个方案、要不要保留旧数据、默认值取多少）。
- **不该用**：能从代码/配置/系统里查到的事实——先查，查不到才问。

## 怎么用

```
request_user_input(question="时间戳按哪种格式存？",
                   options=["毫秒 int（推荐，跨语言无歧义）", "ISO 字符串", "两种都存"])
```

用户在前端卡片上点选项或直接打字 → 答案作为工具结果返回 → 同一轮继续干活。

## 边界

- 无人在线 / 超时 / 用户跳过：工具立刻返回可读说明，模型按默认继续并在回复里说明选了哪个默认，**不重复提问**。
- 选项上限 6 个、每个 80 字符；等待上限 1800s（默认 300s）。
- 提问卡与确认卡共用前端弹窗，但语义不同：确认卡是「拦一下等点头」，提问卡是「问一句等回答」。
